# API Dinâmico - Driver One

API REST desenvolvida em Python com **FastAPI**, utilizando a biblioteca **h3** para indexação espacial geoespacial e integração com o **Supabase**.

---

## Estrutura do Projeto

- `main.py`: Código principal da API FastAPI e lógica de conversão H3 / integração Supabase.
- `requirements.txt`: Dependências do projeto Python.
- `Dockerfile`: Configuração de container Docker para hospedagem no Render.com.

---

## Configuração do Supabase

No painel do seu projeto Supabase, execute o seguinte comando SQL para criar a tabela necessária (`registos_dinamico`):

```sql
create table public.registos_dinamico (
    id bigint generated by default as identity primary key,
    h3_index text not null,
    plataforma text not null check (plataforma in ('uber', '99')),
    valor_dinamico double precision not null,
    latitude double precision not null,
    longitude double precision not null,
    dia_semana integer not null check (dia_semana between 0 and 6),
    hora_registo time not null,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Opcional: Criar índice no h3_index para consultas espaciais mais rápidas
create index idx_registos_dinamico_h3 on public.registos_dinamico(h3_index);
```

## Executando Localmente

1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

2. Configure as variáveis de ambiente (`.env` ou export no terminal):
   ```bash
   export SUPABASE_URL="sua-url-do-supabase"
   export SUPABASE_KEY="sua-chave-anon-ou-service-role-do-supabase"
   ```

3. Inicie o servidor com Uvicorn:
   ```bash
   uvicorn main:app --reload --host 0.0.0.0 --port 8000
   ```

## Exemplo de Requisição (POST `/api/v1/dinamico`)

**Endpoint:** `POST /api/v1/dinamico`

**Corpo da Requisição (JSON):**
```json
{
  "latitude": -23.550520,
  "longitude": -46.633308,
  "plataforma": "uber",
  "valor_dinamico": 1.8
```

## Deploy no Render.com

1. Crie um novo **Web Service** no [Render Dashboard](https://dashboard.render.com/).
2. Conecte o seu repositório GitHub contendo este código.
3. Defina os parâmetros:
   - **Environment:** `Docker`
   - **Region:** Escolha a mais próxima (ex: `Ohio` ou `São Paulo`)
4. Adicione as **Environment Variables**:
   - `SUPABASE_URL`: `https://seu-projeto.supabase.co`
   - `SUPABASE_KEY`: `sua-chave-secreta`
5. Clique em **Create Web Service**. O Render irá compilar o `Dockerfile` e disponibilizar sua API publicamente.
